## Usage Notes

1. **Aspect ratios**: Section backgrounds (panoramic) should be 16:9 (1920×1080 or 2560×1440). Content images (square) should be ~800×800 or 1000×1000 pixels.
2. **File format**: Save all as PNG with transparency where appropriate.
3. **Consistency**: Maintain the color palette across all images — primary blues (#2c3e50, #3498db), accent reds (#e74c3c), greens (#27ae60), and oranges (#e67e22).
4. **Style**: Aim for a consistent semi-flat, modern scientific illustration style across all images.
5. **No text in images**: All labels and annotations should be added via Quarto/HTML overlays, not burned into images.
