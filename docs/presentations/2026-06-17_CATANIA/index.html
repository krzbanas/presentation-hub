Elemental Profiling of Oceanic and Non-oceanic Gerridae

Integrating Synchrotron XFM with Explainable AI

June 17, 2026

Why Gerridae?

A natural experiment in elemental adaptation

  • Gerridae (water striders) colonised marine habitats independently multiple times
  • Oceanic genus Halobates — the only truly pelagic insects
  • Freshwater genera (Metrocoris, Ventidius) occupy chemically distinct niches
  • Question: How does habitat chemistry reshape the whole-body elemental fingerprint?

Research objectives


🎯 Three integrated goals

1. Map — Acquire high-resolution synchrotron XFM elemental maps of whole Gerridae specimens from oceanic and freshwater habitats.

2. Quantify — Extract robust per-element descriptive statistics and compare distributions across habitats.

3. Explain — Train a gradient-boosted classifier (XGBoost) on the elemental profiles and interpret predictions with SHAP values to identify the most discriminative elements.

Biological interpretation

🌊 Oceanic enrichment

  • Sr (~11× higher) — seawater Sr incorporated into cuticle
  • Br (~6× higher) — marine halide bioaccumulation
  • Ca (~3× higher) — enhanced cuticular mineralisation
  • Zn, Se — moderately elevated, metalloprotein pools

🌿 Freshwater enrichment

  • Mn (~2× higher) — reflects freshwater trace-metal chemistry
  • Cu (~1.7× higher) — dietary or environmental source
  • K (~1.6× higher) — osmoregulatory differences

⚖️ Habitat-invariant elements

  • Se, As, Ni — fold-change ≈ 1, homeostatic regulation
  • ** Essential trace elements maintained regardless of environment

🤖 XAI confirmation

  • XGBoost selects only 3–4 elements from 16 available
  • SHAP confirms monotonic Ca/Br → oceanic, Mn → freshwater
  • Sparse model = robust, interpretable signature

🔬 Hypothesis for future work

Oceanic Halobates show Sr-enriched cuticular mineralisation as a potential structural adaptation to wave-dominated habitats. XANES at the Sr K-edge and Ca K-edge could confirm whether Sr substitutes into a carbonate or phosphate lattice.

Methodological considerations

Strengths

✅ Non-destructive, whole-specimen mapping at µm resolution

✅ Simultaneous multi-element detection (16 elements)

✅ Quantitative areal densities via fundamental parameters

✅ TreeSHAP provides exact, per-specimen explanations

✅ Reproducible pipeline: R + Quarto + version control

✅ Balanced sample weights handle class imbalance

Limitations & future directions

⚠️ Small sample size (n = 13) — expand to more species

⚠️ Class imbalance (10 oceanic vs 3 freshwater)

⚠️ 2D projection — consider confocal XFM for depth info

⚠️ No chemical speciation — XANES at Ca, Sr, Fe edges

⚠️ Hollow specimens excluded — compare preservation states

⚠️ Nymph vs adult differences merit investigation (MIC6–8)

⚠️ Body-size confounding — mass-normalised comparison needed

Iterative reporting: element exclusion

Show exclusion workflow code 
# ── User-selectable exclusion vector ──────────────────────────
elements_to_exclude <- c("CdL", "PbL")   # ← edit as needed

df_filtered <- df_all |>
  filter(!Element %in% elements_to_exclude)

fc_filtered <- df_filtered |>
  group_by(habitat, Element) |>
  summarise(grp_mean = safe_mean(mean_conc), .groups = "drop") |>
  pivot_wider(names_from = habitat, values_from = grp_mean) |>
  mutate(
    log2_fc   = log2(Oceanic / Freshwater),
    direction = if_else(log2_fc > 0, "Enriched in oceanic", "Enriched in freshwater"),
    Element   = fct_reorder(Element, log2_fc)
  )

ggplot(fc_filtered, aes(x = log2_fc, y = Element, fill = direction)) +
  geom_col(width = 0.7) +
  geom_vline(xintercept = 0, linewidth = 0.8, colour = pal$dark) +
  geom_text(aes(label = sprintf("%.1f×", 2^abs(log2_fc)),
                hjust = if_else(log2_fc > 0, -0.1, 1.1)),
            size = 4.5, colour = pal$dark) +
  scale_fill_manual(values = c("Enriched in oceanic" = pal$ocean,
                                "Enriched in freshwater" = pal$fresh),
                    name = NULL) +
  labs(
    title    = glue::glue("Fold-change after excluding: {paste(elements_to_exclude, collapse = ', ')}"),
    subtitle = "Second-iteration analysis — remaining elements only",
    x = expression(log[2]~"fold-change"),
    y = NULL
  ) +
  theme_xfm(base_size = 20) +
  theme(legend.position = "top")

Conclusions


Key findings

1. Synchrotron XFM resolves distinct elemental fingerprints between oceanic and freshwater Gerridae at 2 µm resolution across 16 elements.

2. Strontium (~11×), bromine (~6×), and calcium (~3×) are the most discriminative elements — pointing to enhanced cuticular mineralisation in oceanic species.

3. XGBoost with TreeSHAP provides transparent, interpretable classification using only 3–4 of 16 available elements.

4. Manganese and copper are enriched in freshwater specimens, while selenium and arsenic are habitat-invariant.

5. P75 thresholding reveals habitat-dependent spatial organisation of element-rich regions.
